## Notable process findings (not fabricated, directly observed this session)

1. **7 of the "canonical" repos were GATED and inaccessible** even with a valid fine-grained `HF_TOKEN` (`whoami` confirmed a valid token for user AdrianMG): `walledai/AdvBench`, `allenai/wildguardmix`, `walledai/XSTest`, `walledai/HarmBench`, `walledai/StrongREJECT`, `allenai/xstest-response`, `sorry-bench/sorry-bench-202503`. HF reports several as `gated="auto"` (nominally auto-approving), but access was not granted to this account. Each was swapped for an accessible mirror/sibling with equivalent content, documented per-row above.
2. **`ToxicityPrompts/PolyGuardMix` is 2.3GB**, not reflected by its `size_categories` tag at search time — only caught by fetching real file sizes via `HfApi(files_metadata=True)`. Swapped for its companion `PolyGuardPrompts` eval benchmark (52.86MB) from the same paper.
3. **`natolambert/xstest-v2-copy` confirmed to lack the `focus` column** present in `Paul/XSTest` — twin-pair joins for XSTest must use `Paul/XSTest` (or the original walledai mirror, if access is later granted) for the join key, and `natolambert/xstest-v2-copy` only for its bonus model-completion columns.
4. **`AlignmentResearch/StrongREJECT`'s default/train preview returned no sample rows** in this run (description and rows both empty) despite `success=True` reporting — flagged for re-verification with an explicit `--config keywords` or `--config violence` before any downstream use.
5. Several accessible mirrors substituted for gated originals have genuinely low download counts (well below their canonical originals) — this is reported honestly per-row as a red flag rather than smoothed over.
