# Specificity and Causality Audits for Activation-Based Safety Readouts

Public-facing web page and compiled paper for the activation-based safety readouts study.

## Layout

| Path | Description |
|---|---|
| `index.html` | Self-contained project page (GitHub Pages entry point) |
| `paper.tex` | LaTeX source of the paper |
| `paper.pdf` | Compiled paper |
| `references.bib` | Bibliography |
| `figures/` | All figures used by the paper and the web page |
| `workspace/` | LaTeX compilation scratch |

## Viewing the page

Open `index.html` in any browser. It has no external dependencies: all CSS and JavaScript are inline, figures are referenced via relative paths to `figures/`, and no network requests are made at load time.
